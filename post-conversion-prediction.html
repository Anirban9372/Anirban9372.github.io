This one started as a straightforward classification task — predict whether a marketing lead converts — and turned into a small lesson about not over-trusting "more powerful" models by default.

The imbalance problem

With roughly 69% of the 10,000 rows labeled "not converted," a model that just predicted the majority class every time would already look deceptively accurate. That meant accuracy alone was the wrong metric from the start — F1 score, which balances precision and recall, was the honest way to judge whether the model actually found converters, not just avoided false alarms.

Three models, one surprise

Logistic Regression
F1 = 0.544
XGBoost
F1 = 0.538
Random Forest
F1 = 0.525

The simplest model — plain Logistic Regression — came out on top, narrowly beating both tree-based ensembles. That's not the outcome you'd expect by default; XGBoost and Random Forest usually have more capacity to capture non-linear patterns. But with a modest feature set and real class imbalance, that extra capacity seems to have bought overfitting risk more than genuine signal.

What this actually taught me

It's tempting to reach for the fanciest model first. This project was a concrete reminder that a well-regularized simple model is a legitimate baseline to beat, not a placeholder to skip past — and that the "best" model is whatever the evaluation metric on your actual data says it is, not whatever has the most parameters.
